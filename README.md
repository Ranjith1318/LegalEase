
# LegalEase

AI-Powered Legal Document Generator

LegalEase is a Generative AI based application that helps users
create customizable legal documents such as NDAs, agreements,
employment contracts and lease agreements.

## Features

- AI-powered legal document generation
- Editable document preview
- TXT export
- DOCX export
- PDF export
- Simple Streamlit interface
- FastAPI backend
- Google Gemini AI

## Tech Stack

- Python
- Streamlit
- FastAPI
- Google Gemini
- python-docx
- FPDF

## Run the Project

pip install -r requirements.txt

Backend:

python -m uvicorn backend.main:app --reload --port 8000

Frontend:

streamlit run frontend/app.py review together
